Order Trader v1.0 — 订单流虚拟盘
=================================

一、启动
  1. 解压 order-trader-v1.0-win-x64.zip 到一个**全新的空目录**（路径不要含特殊符号）。
     不要解压覆盖旧版本目录：旧版本的内置库（numpy 等）会残留下来与新版混在一起，
     可能导致行情加载异常。
  2. 双击 OrderTrader.exe，直接进入主界面，不再有登录界面。
  3. tqsdk 账号已内置在 config\order-trader.json 中；需要更换账号时，点击主界面
     右上角「设置」，修改账号与密码后点「保存并连接」即可，程序会自动重连行情。
  4. 主界面不显示账号名称，只显示行情通道是否已连接。
  5. 行情加载不出来时，双击「检查环境.bat」，把生成的 logs\selftest.txt 发回来即可定位。

二、运行环境
  - Windows 10 / 11 64 位。
  - 发布包若包含 python\ 目录，则已内置 Python 3 与 tqsdk，无需安装任何环境。
  - 若不包含 python\，请安装 Python 3.10+ 并执行：
        python -m pip install -U tqsdk
    程序会依次查找：config\order-trader.json 中的 pythonPath → 程序目录 python\python.exe
    → 系统 PATH 中的 python.exe / python3.exe。

三、主界面
  - 顶部：行情通道状态、账户余额、当日盈亏、手续费、权益（不显示账号名称）。
  - 第二行：实时模拟盘 / 行情回放切换、回放倍速（0.5x / 1x / 2x / 5x / 10x）、
    合约输入框与「添加」、撤销全部、重置账户、设置。
  - 页面标签：共 20 页，前 12 页可用 F1~F12 快速切换，也可鼠标点击。
  - 内容区：当前页面的合约列表，每行显示合约代码、合约名称、最新价、持仓、净盈亏，
    右侧「打开窗口 / 关闭窗口」按钮可单独控制该合约的价格梯子。
    顶部「全部打开 / 全部关闭」可一键控制本页所有梯子窗口。
  - 价格梯子不内嵌在主界面，每个合约都是一个独立窗口，窗口标题就是该合约代码。
  - 右侧面板：账户概览、收益曲线、持仓、逐笔盈亏（含平仓盈亏，手续费单独统计）。

四、合约代码输入
  - 输入短代码即可，无需交易所前缀，程序会自动补全：
        ag2612          → SHFE.ag2612（沪银 2612）
        rb2701          → SHFE.rb2701
        m2601           → DCE.m2601
        SR601           → CZCE.SR601
        IF2601          → CFFEX.IF2601
  - 期权同样只写短代码，字母 C 为看涨、P 为看跌：
        ag2612c13500    → SHFE.ag2612C13500
        m2601c2500      → DCE.m2601-C-2500
        SR601C5800      → CZCE.SR601C5800
        lc2401c100000   → GFEX.lc2401-C-100000
  - 也可以直接粘贴带交易所前缀的完整代码，程序会原样识别。

五、DOM 梯子（独立窗口）
  - 五列：挂单 / 买量 / 价格 / 卖量 / 成交。
  - 价格列：卖价为红色、买价为蓝色，无挂单为灰色；最新价行有绿色上下边线。
  - 第二列（买量）左键挂 1 手、右键挂 2 手（数量可在梯子左侧输入框修改），
    当挂单价触及卖一（红色格子）即成交买入多单。
  - 第四列（卖量）同理；若当前持有多单，第四列挂单为平多，反之为开空。
  - 第五列：500ms 切片的价位成交量，蓝色为主动买、红色为主动卖。
  - 空格：撤销全部挂单；ESC：所有梯子中心复位到最新价；
    滚轮：上下滚动价格梯子。
  - 拖动梯子右边缘 / 下边缘，可同时统一调整所有梯子的宽度 / 高度。
  - 关闭梯子窗口只会隐藏，合约仍保留在当前页面列表中，可从主界面重新打开。

六、行情
  - 实时模拟盘：订阅当前所有页面的合约，按 tqsdk 行情推送生成 tick，本地 500ms 切片。
  - 行情回放：通过 tqsdk 拉取最近 10000 条 tick，按时间戳对齐后多合约同步回放。
  - 手续费：优先使用 tqsdk 合约信息返回的 commission（元/手），缺失时使用配置中的兜底值。
  - 账号认证与行情服务器连接全部由 tqsdk 自己完成；断线后自动重连，间隔从 1 秒指数
    增长到 30 秒上限，无需重启程序。
  - 打开软件后不再等待登录：主界面立即可用，状态栏显示“正在加载行情环境（已等待 N 秒）”，
    行情通道就绪后自动订阅并显示行情。
  - 内置运行时的科学计算库与 PullStackMeter 完全一致（numpy 1.26.4 / pandas 2.2.3 /
    scipy 1.13.1），这是实测最稳、导入最快的组合；桥接进程同时关闭了 OpenBLAS 多线程
    和运行时 .pyc 写入，避免在部分机器上卡在库初始化或磁盘写入上。
  - 首次启动仍可能慢：杀毒软件要逐个扫描 python\numpy 里的几千个文件，第二次启动会
    因为系统缓存快很多。状态栏会显示已等待秒数，不是卡死。
  - 非交易时段没有新 tick，但订阅成功后会立即显示最新一笔收盘行情（五档盘口 + 价格）。

七、配置
  - config\order-trader.json：账号、初始资金、默认手续费、梯子尺寸、20 页合约列表等。
  - logs\order-trader-YYYYMMDD.log：运行日志。
  - logs\selftest.txt：「检查环境.bat」生成的行情环境自检结果。

八、常见问题
  - 提示“未找到 bridge\tqsdk_bridge.py”：请完整解压，不要只拷贝 exe。
  - 提示“未找到 Python 运行环境”：见第二节。
  - 行情连接失败：点击「设置」检查 tqsdk 账号密码，或关闭 VPN/代理后重试。
  - 打开后一直显示“正在加载行情环境（已等待 N 秒）”：先等两分钟；仍然不动就双击发布包
    里的「检查环境.bat」，它会把每个库的加载耗时、账号能否连通行情服务器写进
    logs\selftest.txt，日志里最后一行成功的库就是卡住的位置。
  - 常见卡住原因：
      · 杀毒/安全软件逐个文件扫描或直接隔离了 python\numpy 里的文件
        → 把整个解压目录加入 Windows 安全中心「排除项」，然后重新解压；
      · 程序放在 OneDrive / 坚果云同步目录或网络盘、U 盘里，文件是"按需下载"的
        → 解压到本地磁盘（例如 D:\OrderTrader）；
      · 从压缩包里直接双击 exe、没有真正解压 → 先完整解压再运行。
  - 想加快首次加载：把解压目录加入杀毒软件排除项；不要把程序放在 OneDrive 同步目录
    或网络盘上。
  - 连接失败后程序会自动重连（1、2、4…最长 30 秒一次）；5 分钟仍加载不出行情环境
    会提示失败，请运行「检查环境.bat」看卡在哪一步，或把发布包换到本地磁盘目录后重试。
  - 行情为空：确认合约代码有效且未过期，例如 ag2612、m2601、ag2612c13500。
  - 输入合约后提示“无法识别的合约代码”：检查品种代码是否在支持的交易所品种表内
    （上期所 / 大商所 / 郑商所 / 中金所 / 上海能源中心 / 广期所）。
