Order Trader v1.0 — 订单流虚拟盘
=================================

一、启动
  1. 解压 order-trader-v1.0-win-x64.zip 到任意目录（路径不要含特殊符号）。
  2. 双击 OrderTrader.exe。
  3. 登录界面输入 tqsdk 账号与密码（默认已填 alyzc26 / 130100），点「登录」。
  4. 验证通过后进入主界面。

二、运行环境
  - Windows 10 / 11 64 位。
  - 发布包若包含 python\ 目录，则已内置 Python 3 与 tqsdk，无需安装任何环境。
  - 若不包含 python\，请安装 Python 3.10+ 并执行：
        python -m pip install -U tqsdk
    程序会依次查找：config\order-trader.json 中的 pythonPath → 程序目录 python\python.exe
    → 系统 PATH 中的 python.exe / python3.exe。

三、主界面
  - 顶部：tqsdk 账户状态、账户余额、当日盈亏、手续费、权益。
  - 第二行：实时模拟盘 / 行情回放切换、回放倍速（0.5x / 1x / 2x / 5x / 10x）、
    合约输入框与「添加」、撤销全部、重置账户。
  - 页面标签：共 20 页，前 12 页可用 F1~F12 快速切换，也可鼠标点击。
  - 每个页面可添加多个 DOM 梯子；梯子横向排列，超出宽度时用底部滚动条或鼠标滚轮横向滚动。
  - 右侧面板：账户概览、收益曲线、持仓、逐笔盈亏（含平仓盈亏，手续费单独统计）。

四、DOM 梯子
  - 五列：挂单 / 买量 / 价格 / 卖量 / 成交。
  - 价格列：卖价为红色、买价为蓝色，无挂单为灰色；最新价行有绿色上下边线。
  - 第二列（买量）左键挂 1 手、右键挂 2 手（数量可在梯子左侧输入框修改），
    当挂单价触及卖一（红色格子）即成交买入多单。
  - 第四列（卖量）同理；若当前持有多单，第四列挂单为平多，反之为开空。
  - 第五列：500ms 切片的价位成交量，蓝色为主动买、红色为主动卖。
  - 空格：撤销全部挂单；ESC：所有梯子中心复位到最新价；
    滚轮：上下滚动价格梯子。
  - 拖动梯子右边缘 / 下边缘，可同时统一调整所有梯子的宽度 / 高度。

五、行情
  - 实时模拟盘：订阅当前所有页面的合约，按 tqsdk 行情推送生成 tick，本地 500ms 切片。
  - 行情回放：通过 tqsdk 拉取最近 10000 条 tick，按时间戳对齐后多合约同步回放。
  - 手续费：优先使用 tqsdk 合约信息返回的 commission（元/手），缺失时使用配置中的兜底值。

六、配置
  - config\order-trader.json：账号、初始资金、默认手续费、梯子尺寸、20 页合约列表等。
  - logs\order-trader-YYYYMMDD.log：运行日志。

七、常见问题
  - 提示“未找到 bridge\tqsdk_bridge.py”：请完整解压，不要只拷贝 exe。
  - 提示“未找到 Python 运行环境”：见第二节。
  - 登录失败：检查 tqsdk 账号密码与网络；错误信息会显示在登录界面。
  - 登录较慢：登录前会自动检测直连/系统代理是否可达天勤服务器（各 5 秒），
    登录页会显示当前阶段（检测网络、连接行情服务器、已等待 N 秒）；
    网络正常时通常 1~3 秒完成，VPN/代理异常时请先关闭代理再试。
  - 行情为空：确认合约代码有效且未过期，例如 SHFE.rb2701、DCE.m2601。
